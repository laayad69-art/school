## 📋 نظرة عامة

ملف HTML وحيد كامل الاكتفاء يتيح لطلاب **أم رماد الثانوية المشتركة** الاطلاع على نتائجهم الدراسية بشكل فوري وآمن دون الحاجة إلى خادم أو قاعدة بيانات خارجية. يكفي فتح الملف في أي متصفح حديث.

---

## ✨ المميزات

| الميزة | التفاصيل |
|---|---|
| 🔍 **بحث فوري** | البحث بالرقم القومي (14 رقماً) مع تحقق تلقائي من الصحة |
| 📊 **عرض شامل للدرجات** | المواد الأساسية + مواد الأنشطة في بطاقة منظمة |
| 🧮 **حساب تلقائي** | المجموع الكلي والنسبة المئوية تُحسب لحظياً |
| 🎨 **تلوين الدرجات** | نظام ألوان لتمييز مستوى الأداء (ممتاز / جيد / مقبول / ضعيف) |
| 📸 **تحميل كصورة** | تصدير بطاقة النتيجة كصورة PNG بجودة عالية |
| 🔒 **خصوصية الرقم** | الرقم القومي يظهر مخفياً جزئياً في البطاقة |
| 📱 **متجاوب بالكامل** | يعمل على الجوال والتابلت والكمبيوتر |
| 🌙 **وضع داكن** | تصميم داكن أنيق بألوان ذهبية |

## 🚀 طريقة الاستخدام

1. افتح ملف `نتائج_الطلاب.html` في أي متصفح (Chrome / Edge / Firefox)
2. اكتب الرقم القومي المكون من **14 رقماً** في خانة البحث
3. اضغط **"عرض النتيجة"** أو مفتاح **Enter**
4. تظهر بطاقة النتيجة بجميع الدرجات والمجموع والنسبة
5. اضغط **"تحميل النتيجة كصورة"** لحفظ البطاقة كـ PNG
